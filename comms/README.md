# Communication experiments

This area will contain Aroh-to-Aroh messaging and calling experiments.

V1 rules:

- use established cryptographic libraries and reviewed protocol designs;
- separate identity, key agreement, transport and media concerns;
- assume servers and networks are untrusted;
- minimise metadata where practical;
- support key rotation and device removal; and
- do not claim production-grade security before independent review.

Carrier calls and SMS are device-enablement work. Aroh encrypted messaging is a
separate protocol experiment.

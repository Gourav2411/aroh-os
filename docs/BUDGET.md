# Prototype budget guardrail

The ₹2,00,000 allocation is a ceiling, not a spending target. Existing donor
phones should keep the first four-month prototype materially below it.

| Category | Working range |
| --- | ---: |
| Batteries, donor-device repair and spare parts | ₹10,000–₹25,000 |
| USB hubs, cables, adapters and debug accessories | ₹5,000–₹15,000 |
| Development storage, backup media and power protection | ₹10,000–₹25,000 |
| Test SIMs, data and communication services | ₹3,000–₹8,000 |
| Model, API and temporary compute experiments | ₹10,000–₹30,000 |
| Domains, basic legal and trademark screening | ₹10,000–₹30,000 |
| Specialist hardware/firmware help, if required | ₹20,000–₹50,000 |
| Contingency reserve | ₹40,000–₹80,000 |

## Spend gates

- Do not buy replacement hardware before device intake and bootloader research.
- Do not commission custom boards for V1.
- Prefer reversible tools and reusable lab equipment.
- Approve cloud/model spend weekly with a hard cap.
- Keep at least ₹50,000 uncommitted until telephony feasibility is known.

The premium camera, display, charging and enclosure features belong to a later
custom-hardware prototype. They are not required to validate the Aroh OS
interaction model on donor phones.
